# Starblu Performance Hub

Crie uma Landing Page profissional, premium, moderna e altamente orientada à conversão para a STARBLU — empresa especializada em Medicina Ocupacional, Segurança do Trabalho, SST e eSocial, com atuação em Blumenau e região.

IMPORTANTE:

Esta página será utilizada principalmente para campanhas de Google Ads e geração de leads B2B. Portanto, não crie um site institucional tradicional. Crie uma LANDING PAGE DE PERFORMANCE, com narrativa comercial, alta clareza, autoridade, prova social, redução de objeções e CTAs distribuídos estrategicamente.
